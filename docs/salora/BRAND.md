# SALORA Brand Foundation

Company: **SALORA AI**  
Product: **SALORA OS**  
Tagline: The World's First AI Learning Operating System.  
Promise: Learning that stays on the line.

Name: śālā (hall) + ōra (speech). A hall where speech stays.

## Mission

Keep a learner on the line: the same host, the same licensed memory, the same next attempt.

## Vision

The world's first AI Learning Operating System. Not a chatbot. Not a dashboard. A hall for practice that does not restart the person.

## Personality

Steady Light. Sage and caregiver. Calm, exact, warm without cling.

## Color

| Token | Light | Dark | Role |
|---|---|---|---|
| Pulse | `#2F6F5E` | `#6FBF9A` | One brand note. Primary and host presence |
| Canvas | `#F7F4EE` | `#121410` | Quiet room |
| On-pulse | `#F7F4EE` | `#121410` | Ink on pulse |

Semantic success / warning / error stay separate. Pulse is not error.

## Type

- Text: Public Sans (`--font-public-sans`)
- Mono: Commit Mono (status, labels)
- A third family is a defect

## Motion

Verbs only: arrive, leave, confirm, fail-closed, progress, takeover.  
Duration: 180ms short, 320ms medium. Ease: decelerate into rest.  
Reduced motion: instant state. Meaning remains.

## Mark

`/salora-mark.svg` — hall arch + speech line on pulse.  
`/salora-mark-dark.svg` — inverted for dark header.
