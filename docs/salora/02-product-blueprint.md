# SALORA OS — Product Blueprint

What the product contains.

Architecture says how objects are organized.  
This file says which capabilities exist and why.

Not how it looks.  
Not how it is engineered.  
Every module and workflow teams may build.

If a capability is not here and not added by a written amendment, it is not on the roadmap.

---

# Volume I — Product Map

Major product areas. Each exists for one job.

**Home**  
Orients the person. Answers where I am and what the one next attempt is. Not a feed. Not a store.

**Learning**  
The attempt itself: lesson, practice, recall, revision. The kernel surface.

**AI Tutor**  
The host in the room. Relationship, greeting on first day only, return without restart, escalation offer.

**AI Workspace**  
Operator room for routing, guest health, evaluation. Traces without tapes. Not a learner destination.

**Memory**  
The list of licensed fields. Read, correct, forget. Shared projections visible as projections.

**Assessments**  
Items, attempts, scores of a class of skill, human review path. Not a public leaderboard.

**Progress**  
States and due revisions. A question with an answer. Empty is drawn. Not a vanity graph.

**Parents**  
Time, topics, completion, next step. Rare safety. No eavesdrop.

**Teachers**  
Class pulse, assignment, risk, override. Colleague tools.

**Classroom**  
The group object: roster, work, pulse. Not a surveillance wall.

**Enterprise**  
Tenancy, contract, health, aggregates, policy. No learner speech as entertainment.

**Settings**  
Consent, language, accessibility, devices, notifications, people links.

**Search**  
Memory prosthetic over the taxonomy. Confirm before leaving a live session.

**Notifications**  
One fact, one optional action. Quiet default. Never a second tutor.

**Profile**  
Chosen name, language, goals they show, what they allow, export and delete.

**Knowledge Base**  
Retrievable curriculum and resources with sources. Not a second tutor personality.

**AI Marketplace**  
Not a default area. A guest may be added only as a named specialist with a curriculum subgraph, evaluation seat, and way home. There is no storefront of personalities. If a partner guest is offered, it appears as a licensed specialist inside Learning, not as a mall.

# Volume II — User Journey

States for each major journey. Architecture Volume IV defined the five acts. Here the product states are named.

## First launch

States: Arriving → Language chosen → Needful permission asked → First host present → First attempt offered → First attempt done or left → Thread exists or guest-only hour ended.

The product does not add a tour state. Teaching is the tour.

## First lesson

States: Item presented → Learner produces → Feedback → One next step → Set ends.

No biography harvest. No guest unless the item requires a named skill.

## Daily learning

States: Today’s primary shown → Practice → Optional recall → Enough → Quiet exit.

Missed yesterday is a scheduling fact, not a moral state.

## Weekly review

States: Due items listed → Recall set → Reflection beat → Next week’s edge named.

A weekly review that is a dashboard without recall is not a review.

## Exam preparation

States: Goal dated → Weak class identified → Mixed practice → Sample assessment → Human path if the record will be official → Rest.

Exam mode does not remove Stop, dignity, or fail-closed.

## Teacher onboarding

States: Identity → Class created or joined → Subject bound → First assignment → First pulse readable → Override understood.

## School onboarding

States: Contract → Admin → Policy → Roster → First classroom live → Export path tested.

## Parent onboarding

States: Invite → What-is-seen explained → First report understood → Quiet default set.

## Voice learning

States: Mic permitted or refused without punishment → Host speaking → Learner speaking → Barge-in possible for Stop/Help/safety → Drop recovered in the same room.

Refusal of mic opens typed path when present.

## Offline learning

States: Honest offline → Cached last lesson and licensed memory readable → No pretend guest → Sync later without duplicate attempts.

If we cannot teach, we say we cannot.

## Returning after months

States: Same host → Licensed memory offered as a list, not a speech → One gentle placement item → Resume the life, not the old session object.

No “we missed you” theater. No stranger greeting.

## Changing language

States: Language chosen → Script respected → Host continues → Memory labels follow language → In-flight item asked before replace.

Hindi is Devanagari, never Roman as a default.

## Changing device

States: Identity → One live session rule → Takeover confirm → Same thread.

A new device is not a new person.

# Volume III — Learning Flows

Each flow is a product sequence. Features must declare which flow they serve.

## Learning Session

Start host → Offer last thread or new item → Encode (short) → One check → End or move to Practice.

Purpose: first encoding without a lecture costume.

## Revision Session

Due or Forgotten items → Produce first → Feedback → Reschedule → Stop when enough.

Purpose: spacing. Not a new course.

## Practice Session

Edge item → Attempt → Hint or smaller isomorphic item on miss → Repeat → One reflection optional.

Purpose: deliberate practice. Guests may enter and must leave.

## Assessment Session

Disclose that this is a sample → Closed items by tools; judgment of a child not by tools alone → Score the attempt → Show what was wrong and what to try → Human path if permanent record.

Purpose: measure a class of skill.

## Reflection Session

After a set: what was hard → one sentence or one tap → stored only if licensed.

Purpose: metacognition. Not a journal exam in the mouth.

## Goal Setting

Name a skill or exam → time horizon → what “enough” means → visible in Home as the reason for next items.

Purpose: autonomy. Not a lock-in.

## Planning

Planner chooses next pedagogical move: ask, hint, item, guest, stop, human.

Purpose: one next move. Not a five-act plan spoken aloud.

## AI Coaching

Host reviews licensed states and names one weakness and one next attempt.

Purpose: coach the practice, not the identity. No invented biography.

## Memory Review

Open the list → correct a field → forget a field → see who can see a projection.

Purpose: licensed memory as a product, not a policy PDF.

## Mistake Review

Last misses of a class → produce again or see the smaller item → no shame copy.

Purpose: error recovery. Not a highlight reel.

# Volume IV — AI Capabilities

Capabilities are seats and tools. They are not a catalog of personalities.

**Tutor (Host)**  
Owns relationship, return, refusal of unsafe guests, escalation offer, the room.

**Planner**  
Chooses the next pedagogical move from licensed state and the graph.

**Coach**  
Names one weakness and one next attempt. Does not moralize.

**Examiner**  
Runs an Assessment Session. Does not own the permanent record without a human path.

**Translator**  
A tool. Changes language or script. Does not change the host identity.

**Research Assistant**  
Retrieves resources with sources. For older learners and teachers. Not a silent child-web.

**Writer**  
Helps compose. Does not submit as the learner when the goal is the learner’s skill.

**Reasoner**  
Used when the task needs steps. Traces are not personality.

**Vision**  
A tool on requested images. No face required. No silent camera.

**Speech**  
One pipeline into the room. Listen and speak. Not a second brain.

**Memory (capability)**  
Read and write licensed deltas. List and forget. Never a hidden diary.

**Goal Manager**  
Holds goals the person set. Does not invent life plans.

**Reflection Coach**  
Asks one metacognitive question after a set. Stops.

Guests (math, later others) are Tutor-shaped specialists with a subgraph. They are not extra capabilities in this list; they are guests of the Tutor.

# Volume V — System Architecture (Conceptual)

Logical systems. Not services, not code.

**User System**  
Accounts, roles, guest and anonymous modes.

**Identity**  
Stable person and stable host. Agents have ids. The host id does not change when a model changes.

**Learning Engine**  
Items, states, spacing, graphs, next item.

**Memory Engine**  
License, list, project, forget, promote session to long-term only with consent.

**Voice Engine**  
One path: hear, speak, barge-in rules, reconnect as same room.

**AI Routing**  
Explainable choice of host or named guest. Confidence, one clarification, one retry, fail to host.

**Assessment Engine**  
Items, tool scores, human review flag, no feed.

**Analytics**  
Events without transcripts. Health, completion, fail-closed, latency. Not “engagement” as a moral.

**Permissions**  
Capability flags. Guest cannot exceed host. Host cannot exceed consent.

**Sync**  
One attempt, many devices. No forked tutors. No duplicate writes of the same try.

**Offline**  
Honest absence. Readable cache. No pretend online guest.

**Search**  
Index of taxonomy objects the role may see.

**Notification Engine**  
Quiet. One fact. Life-safety may break quiet. Marketing may not.

# Volume VI — Product Ecosystem

Supported environments and what they are for.

**Mobile** — Primary learning device. Attempt, voice, stop.  
**Tablet** — Learning plus light teacher or parent instruments.  
**Desktop** — Full instruments for the role that needs density.  
**Web** — Same OS in a browser. Not a brochure.  
**Wearables** — Glance, pause, stop, due. Not teaching.  
**Vision Devices** — Optional spatial pointing. Learning still works without a face.  
**Classroom** — Shared and individual modes. Teacher override. No secret observers.  
**Enterprise Dashboard** — Health, policy, aggregates.  
**Teacher Console** — The Teacher Workspace on any capable device.  
**Parent Console** — The Parent Workspace.  
**Future Interfaces** — Inherit identity, memory, host, stop. New sensors optional.

# Volume VII — Product Roadmap Layers

What belongs where. A layer may not steal the kernel of the layer below.

**Core Layer**  
Host, session continuity, licensed memory, stop, language, forget, typed fallback, fail toward tutor, privacy-safe events.

**Professional Layer**  
Goals, spacing, assessments with human path, search, planning, mistake review, more named guests with curriculum.

**Institution Layer**  
Teacher, parent, classroom, assignment, pulse, override, school policy, roster.

**Enterprise Layer**  
Tenancy, regions, contracts, control plane, audit aggregates, retention, export.

**Developer Layer**  
Documented extension for guests and resources that cannot break host, consent, or fail-closed. No marketplace of souls.

**Future Layer**  
Teach-others, vision as optional tool, wearables, automotive short path, research workspace. Never a second voice pipeline. Never default tape.

A demo that lives only in Future and skips Core is not a release.

# Volume VIII — Product Principles Applied

How permanence appears as product behavior. Not a rewrite of the Constitution.

**Continuity**  
Resume is the same item. Reconnect is not a handoff. A new device asks to take over. Months later, the host is not a stranger.

**Trust**  
Permissions at need. Refusal without punishment. Errors name what happened and what to do. No stack in the lesson.

**Memory**  
A screen that lists fields. Forget completes there. Shared views are labeled as projections.

**AI**  
The host is named as the tutor. A guest is named when it enters and when it leaves. Uncertainty asks one question. No hidden second brain on a path called deterministic.

**Learning**  
Ask before tell when the goal is skill. One difficulty. Next item from last miss. A solved step is not a speech.

**Accessibility**  
Every commitment has a labeled, keyboard path. Meaning is not color-only. Voice-only can finish a Core attempt. Hover is never the only way.

# Volume X — Future Expansion

2050, Constitution unchanged.

The hall is still a hall. The host is still a host. Memory is still licensed and listed.

What may grow:

- More subjects as graphs, not as new companies.
- More named guests with curricula, each with a way home.
- More rooms for institutions that still cannot buy a tape.
- More devices that inherit one identity.
- Teach-others at civic scale: a mastered learner explaining to a younger one, with dignity on both sides.
- Knowledge that cites the living world, still retrieved, still not invented biography.
- Evaluation of models as a public duty inside the company, still sitting three live sessions after a swap.

What may not grow:

- A second kernel.
- A marketplace of fake companions.
- Default recording as a feature of progress.
- A score that outranks a child’s dignity.
- An intelligence that must be seen thinking in order to be trusted.

The product expands by making the next attempt cheaper, clearer, and more honest in more places.  
It does not expand by becoming a city of apps that forget the person at every gate.
