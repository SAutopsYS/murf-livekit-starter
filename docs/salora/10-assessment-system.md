# SALORA OS — Assessment & Evaluation System Constitution

Phase 7.

The Constitution defines why assessment exists.  
The Learning System defines how learning happens.  
The Knowledge System defines what is learned.

This file defines how learning is measured, validated, interpreted, improved, and certified.

Not an exam engine.  
Not a grading policy.  
Not question banks.

The permanent Assessment Science and Educational Evaluation Constitution.  
Assessment designers, psychometricians, learning scientists, curriculum architects, AI engineers, teacher partners, researchers, accreditation, and product follow this file.

Learning System Volume VI named assessment kinds.  
Knowledge System named the `assesses` edge and the credential object.  
AI System named the Examiner seat.

This file is the law of evidence.

If a score, badge, or certificate cannot name the class it sampled, the items that sampled it, the human path when it is official, and the validity claim, it is not an assessment. It is a decoration.

# Volume I — Assessment Philosophy

Assessment is a sample of a class of skill.  
It is not a verdict on a person.

**Assessment as learning**  
The act of producing is itself practice (Roediger & Karpicke). A check that teaches nothing but a number has failed even if the number is reliable.

**Assessment for learning**  
Formative use: the next item, hint, or path changes (Black & Wiliam). This is the default in the hall. Most voice checks live here. They do not become a record unless a human path says so.

**Assessment of learning**  
Summative use: a disclosed sample after a stretch, for an outcome the person was told. Of-learning is rare, labeled, and expensive in dignity. It is never the ambient mode of the OS.

**Mastery over scores**  
A score is a compression. Mastery is stability across spaced transfer items. We may store a score of an attempt. We do not let a single number outrank the state on the graph.

**Evidence over performance theater**  
A fluent identical drill is weak evidence of a class (Messick: construct validity). A quieter transfer item is stronger. Performance that exists to look busy is not evidence.

**Growth over comparison**  
The question is whether this person can do more of this class than before. The question is not where they sit in a room of children. Ranking is not a measurement purpose here.

**Human-centered evaluation**  
A tired mouth, a second language, a cheap mic, and a shared house are part of the measurement context. We design for them. We do not call that noise and then punish it.

**Fairness**  
The same class, the same dignity, accommodations that keep the construct, no cultural trap as a “hard item.” Unfairness is a validity failure, not a PR problem.

**Transparency**  
They know when a set is a sample, what class it claims, what will be stored, and who can see a projection. Secret scoring is not assessment. It is surveillance.

**Lifelong assessment**  
Mastery decays. Credentials that cannot decay are lies. A returner gets a diagnostic, not a stranger’s exam and not a forever trophy.

# Volume II — Assessment Architecture

Every assessment event is one of these types.  
A quiz skin is not a type.

**Diagnostic** — What is already there. Placement and skip/descend. Short. Not a verdict. Not a permanent rank.

**Placement** — A diagnostic used to choose a path or a course slice. Reversible. A teacher may override.

**Formative** — During learning. The next attempt is the feedback. Default. No official record unless promoted by a written rule and a human.

**Summative** — Disclosed sample after a stretch. Outcome path named in advance (self, teacher, parent projection, credential).

**Competency** — Several skills of one competency, including transfer. One identical drill cannot carry a competency.

**Performance** — A longer doing judged by a rubric. Child judgment is not a tool alone.

**Oral** — First-class. Same disclosure and record rules. A cheap mic is a context, not a character flaw.

**Practical** — A procedure in the world or a constrained simulation. Safety first. Not pretend lab authority.

**Project** — Across sessions. Criteria up front. Not a portfolio of tapes.

**Portfolio** — Selected artifacts the person chose to keep. Licensed. Erasable. Not an ambient scrape of everything they said.

**Reflection** — A short metacognitive sample. Scored, if at all, as completeness of a strategy — never as a soul.

**Certification** — A claim to the world. Human path. Disclosed. Competency sample. Not attendance.

## Relationships

| Relation | Meaning |
|---|---|
| `samples` | This event samples this skill or competency |
| `contains` | This event contains these items |
| `promotes-to` | Formative evidence may promote to a record only by rule |
| `places-into` | Diagnostic/placement points at a path |
| `informs` | Result changes Planner next move |
| `requires-human` | Official, high-stakes, or judgment |
| `appeals-to` | A human review node |
| `supersedes` | A later sample replaces an earlier claim of the same class |
| `maintains` | A later sample keeps a mastery or credential honest |

A summative that cannot name `samples` and `contains` is not summative.  
A certification without `requires-human` does not ship.

# Volume III — Competency Architecture

A competency is a class of performance that transfers.  
It is not a badge name.  
It is not a personality.

**Knowledge competencies** — Use of concepts and principles in the graph. Sampled by explanation, near-miss rejection, and application — not by a fact list alone.

**Skill competencies** — Observable hard-skill clusters (Learning System Volume V). The default of this OS.

**Behavioral competencies** — Performances in situations (turn-take, ask a clear question). Practiced in scenarios. Not a hidden conduct grade. Not a dossier.

**Meta competencies** — Plan a set, notice a miss, choose a hint. Sampled rarely. Never a secret “how they think” profile.

**AI literacy** — They can use a host, hear a hedge, see a guest leave, open Memory. Sampled by acts, not by a speech about our architecture.

**Communication** — Speak, listen, write, read, switch language. Native script. Oral assessment is first-class. Accent is not the construct unless the credential says pronunciation is the construct — and then we say so.

**Collaboration** — Visible room, shared task. A dropped peer fails to host. We do not score a child for a peer who left.

**Creativity** — A new instance of a class. Slow. Not completed by one spoken turn. Rubric, human path if official.

**Critical thinking** — Source, near-miss, check a step. On real items. Not a poster test.

**Leadership** — Only for older learners who asked or whose program named it. Never inferred from a child’s voice. Never a playground rank.

**Professional competencies** — Adult and older-student programs. Same evidence rules. An employer does not receive a childhood.

Soft, behavioral, and leadership competencies never become a shadow report card. If we cannot show the person the claim, we do not store the claim.

# Volume IV — Mastery Architecture

Product Architecture named learning states (Not Started … Mastered … Archived).  
This volume names quality of a class and how it moves.  
A state and a mastery level may both be true. They must not contradict.

**Beginner** — First encoding or first attempts. High support. Not a slur.

**Developing** — Practice at the edge. Hints still in play. Transfer not yet stable.

**Proficient** — Accurate on isomorphic items with faded support. Near transfer beginning.

**Advanced** — Transfer across surfaces. Interleaving holds.

**Expert** — Stable across spaced transfer; can teach or adapt the procedure. Rare. Not a default trophy. Not claimed from a weekend.

**Maintenance** — Scheduled return while Mastered. The honest companion of Expert and Mastered.

**Regression** — A failed recall or transfer after a gap. Maps to Forgotten or Needs Revision. Not shame. A scheduling and teaching fact.

**Recovery** — After miss, drop, or fail-closed: same thread, smaller demand. Assessment in recovery is formative unless disclosed otherwise.

**Transfer** — Success on a new item of the class. The gate from Proficient toward Advanced and Mastered.

**Long-term retention** — Success after a longer gap (Cepeda). The gate that keeps Mastered honest.

## Transitions

Beginner → Developing when they can attempt a step without the full speech.  
Developing → Proficient when isomorphic accuracy holds as scaffolds fade.  
Proficient → Advanced when transfer items hold.  
Advanced → Expert when they can explain or adapt, and retention holds.  
Any held level → Regression on failed spaced transfer.  
Regression → Recovery → the last honest level, not a restart of the person.  
Any level → Maintenance while Mastered.  
Without Maintenance, Mastered and Expert decay. Decay is a transition, not a scandal.

A score may inform a transition. A score may not skip Transfer and Retention and mint Expert.

# Volume V — Question Architecture

A question is an item that samples a class.  
It has a type, a criterion, a graph binding, and a use (formative or summative).  
A bank is a drawer. This is the law of the item.

**Recall** — Produce a fact or a step from memory. Necessary. Not sufficient for mastery.

**Understanding** — Explain, choose an example, reject a near-miss.

**Application** — Use the class on a new isomorphic or near-transfer item.

**Analysis** — Separate parts, find the failed step, compare two cases.

**Evaluation** — Judge against a criterion they were taught. Not a moral verdict on a peer.

**Creation** — Produce a new instance. Slow. Rubric. Human path if official.

**Adaptive** — Next item from last attempt (smaller isomorphic or harder transfer). Adaptation is of difficulty, not of truth. Adaptive is not a maze that traps.

**Oral** — Spoken production. Same Bloom class as its written twin. Mic quality is context.

**Scenario** — Soft skill or apply in a situation. One primary. Stop remains.

**Simulation** — Constrained model of a system. Assumptions labeled. Safety first.

**Reflective** — After a set. One beat. Not an essay exam in the mouth.

Rules:

- Every item names the class it `assesses`.
- Every closed item has a checkable criterion or a tool.
- Every open item has a rubric before it is used for a record.
- Identical-item repeats do not count as transfer.
- Trick items that punish language or culture are bias, not rigor.
- An item that requires a face, a hover, or a fashion of UI is invalid for Core.

# Volume VI — Feedback Architecture

Learning System Volume VIII is the pedagogy of feedback.  
This volume is feedback attached to a sample.

Feedback exists to improve the next attempt.  
A number without a next act is an incomplete result.

**Immediate** — Closed steps and oral form: the next sentence. Default for formative.

**Delayed** — Until the sample is finished, when seeing the key would destroy the construct. Then full corrective plus next act.

**Corrective** — Name the miss. Show the class. Do not name the soul.

**Hints** — Formative only, one at a time. A hint on a disclosed summative must be in the published rules or absent.

**Scaffolding** — Visible on formative. Faded as they rise. On certification, scaffolds are accommodations, declared, not secret ease for some and not others without a rule.

**Reflection** — After the set. Optional on formative. Not a second exam.

**Confidence feedback** — They may state confidence. We may show calibration later. We do not mock a miss they were sure of. That miss is a teaching target.

**Error analysis** — The failed step or the near-miss they chose. Item-fault is separated from learner-fault (Knowledge System analytics).

**Next steps** — One next item or one human act. Not a five-act plan.

**Human feedback** — Teacher comment on judgment tasks. Outranks AI draft. The person can read it. It is not a gossip note to a feed.

A leaderboard is not feedback.  
A streak threat is not feedback.

# Volume VII — Measurement Architecture

A measure has a construct, a unit, and a use.  
Measurement serves learning. It never serves ranking.

**Accuracy** — Correctness on the class. Primary for closed skills.

**Fluency** — Accuracy with low enough load to take a next demand. Not the same as speed.

**Speed** — Time on a task. Allowed only when speed is the construct (a fluency drill they were told is timed). Never a hidden race. Never a shame clock on a child thinking.

**Retention** — Accuracy after a gap. First-class.

**Transfer** — Accuracy on a new item of the class. First-class.

**Confidence** — Stated or revealed. Compared to accuracy. Calibration is the measure, not swagger.

**Consistency** — Stability across items of the class, not across a mood.

**Progress** — Change in mastery level or state over spaced samples.

**Practice quality** — Edge, faded hints, transfer present. Not count of taps.

**Mastery growth** — Movement along Volume IV, including decay. Growth that ignores decay is a vanity curve.

Rules:

- No composite “engagement score” as a learning measure.
- No public rank.
- No utterance as a measure.
- Context (language, device, drop) is recorded as context, not as a deficit of character.
- A measure we cannot explain to a teacher in one breath is not shipped as a number on a child.

# Volume VIII — AI Assessment

AI assists assessment. Humans remain accountable.

**Automated scoring** — Closed items, schemas, tools. The mouth does not outrank the tool on a closed fact. Invalid output is a fail of the scorer, not a creative mark.

**Essay evaluation** — Draft rubric notes for a teacher. Not an official mark without human review when the record is permanent or the learner is a child.

**Oral evaluation** — May score closed oral (a number said, a form produced). May draft notes on a spoken paragraph. Accent and mic are not the construct unless declared. Official oral of a child: human path.

**Coding evaluation** — Constrained tests and static checks. Not unbounded execution as their identity. Style as character is forbidden.

**Project review** — Checklist and rubric draft. Human owns the send.

**Rubric support** — AI may apply a published rubric as a draft. It may not invent a rubric at scoring time.

**Feedback generation** — Obeys Language System and Volume VI. No shame. No invented miss.

**Hallucination prevention** — No invented score, criterion, or memory of an answer they did not give. A missing audio is a missing attempt, not a zero of the soul.

**Human review** — Required for official, high-stakes, judgment, certification, and any child permanent record.

**Appeals** — A human can reopen. AI does not hear the appeal as a second judge wearing a wig. The teacher or named reviewer does.

The Examiner seat may run a session. It may not own the record.  
A model swap does not rewrite yesterday’s official mark without a written regrade rule.

# Volume IX — Teacher Evaluation System

The teacher is the accountable human for classroom and official claims.

**Teacher review** — They see items, outcomes, rubric drafts — not tapes.

**Manual override** — Stands on item, level, guest, and record. The OS does not re-route behind them.

**Rubrics** — Published before the task when the task is of-learning. Shared language. Not a private curve.

**Classroom assessment** — Oral, practical, observation they chose to record as an outcome. Observation is their note, not our microphone.

**Intervention** — Triggered by Forgotten, failed transfer, or distress — not by a low “engagement” score. Human act.

**Professional judgment** — Outranks the Planner and the Examiner on that learner in that class. Outranked only by safety and dignity.

**Student conferences** — The OS may summarize states and next steps. The conference is human. No surprise dossier.

**Parent communication** — Time, topic, next step, disclosed samples they are allowed to see. Teacher sends. No quote.

**Evidence review** — They can open the items that produced a claim. If they cannot, the claim is invalid.

**Certification approval** — A named human signs. A model does not.

A teacher who cannot explain a mark in one breath has been given a bad assessment, not a bad student.

# Volume X — Credential Architecture

A credential is a claim to the world about a demonstrated class.  
It is never attendance.  
It is never a streak.  
It is never a weekend of sitting with a guest.

**Badges** — Small, optional, local. If used at all, they point at a real sample. They do not decorate Home. They do not shame their absence.

**Certificates** — Formal claims. Human path. Class named. Date. Version of the graph. Decay or maintenance rule stated.

**Competencies** — The object the credential should point at. A certificate without a competency is a letterhead.

**Learning records** — The person’s outcomes and states they own. Exportable. Privacy-safe. No utterances.

**Digital credentials** — Verifiable as a document of a sample, not as a public childhood. Revocable when the claim is withdrawn. Not a chain that outlives forget.

**Skill passports** — A bundle they chose to show. They pick the page. An employer or school sees what they presented, not our graph of their mouth.

**Academic credit** — Only with an institution’s human path and a valid sample. We do not invent credit.

**Professional credit** — Adult programs. Same evidence. Separate from any child record.

**Lifelong records** — They persist as the person allows. Mastery decay is visible. A ten-year-old certificate that cannot admit decay is a costume.

**Verification** — A third party can verify that we issued a claim about a class on a date — not replay the attempt, not hear the child.

If removed, does the attempt get worse? If a badge’s only job was delight, it was already illegal under Experience. Remove it.

# Volume XI — Fairness & Integrity

Trust is a design of the sample, not a poster.

**Bias detection** — Item and form review for culture, gender, board-as-world, language load that is not the construct, and regional mockery. Differential item functioning is a research duty (Volume XIII). A biased item is retired, not “hard.”

**Accessibility** — Voice and type, time, language, stop. An assessment that requires a hover, a color, or a face is invalid for Core.

**Accommodations** — Extra time, typed instead of oral, larger type, human reader — declared, construct-preserving. An accommodation is not a leak of the key. It is fairness.

**Academic integrity** — When the goal is their skill, we do not become the author. When a set is of-learning, the rules of help are published (hints or not). We do not run a secret sting.

**Identity verification** — For official adult or institutional claims, prove the account as the platform already proves it. No face required to learn. No child’s face as a proctor product. A school that needs a human proctor uses a human.

**AI usage policies** — Stated per task: allowed as hint, forbidden as author, required as tool. The host obeys the task rule. It does not wink.

**Appeals** — Written path. Human. Time-bounded. The item and the rubric are visible. The person is not punished for asking.

**Transparency** — Purpose, class, storage, audience, help rules — before a summative or certification starts.

**Reliability** — A sample too short to be stable is not used for a credential (Volume XIII).

**Ethical assessment** — No surprise high-stakes. No public rank. No sale of results. No use of a miss to market. Distress stops the sample and offers a human.

Integrity that requires a camera in a bedroom is not integrity we will implement.

# Volume XII — Assessment Analytics

Analytics improve instruction and items. They do not create competition.

**Knowledge gaps** — Prerequisites that fail when a later sample fails.

**Skill gaps** — Classes in Regression or Developing longer than the path expected — for Planner and teacher, not for a wall.

**Mastery distribution** — Of a class, for a teacher of a class. Not a public histogram of named children.

**Retention curves** — Recall after gaps. Educational north star beside transfer.

**Learning velocity** — Change across spaced samples. Not items per minute.

**Intervention success** — Did a human or a smaller path improve the next sample? If not, the intervention was theater.

**Assessment quality** — Item-fault rate, empty-construct items, hint leakage on summative, drop during sample.

**Rubric reliability** — Agreement among humans, and human vs AI draft. Low agreement means the rubric is not ready, not that the child is chaotic.

**Confidence calibration** — Overconfidence on a class is a teaching target.

**Educational outcomes** — Transfer, retention, mastery that admits decay. Not certificate count.

No leaderboard.  
No teacher rank as a product.  
No “hardest working student.”  
A metric that rises while dignity falls is retired.

# Volume XIII — Research & Validation

Every assessment used for a record or a credential demonstrates validity evidence.  
A pretty form is not evidence.

**Psychometrics** — We use the craft; we do not worship a single model. The construct is named first. The math serves it.

**Reliability** — Repeated samples of the same class agree enough for the use. A three-item quiz does not certify a competency.

**Validity** — We sample the class we claim (Messick). Consequence is part of validity: if the sample harms the try or ranks children, validity has already failed.

**Standard setting** — “Enough” for a level or a credential is written, reviewed, and not a mood of a model. Teachers and experts set it. AI may simulate; it does not set.

**Item analysis** — Difficulty, discrimination, item-fault, bias flags. Items that all fluent learners miss are suspects. Items that punish a locale are retired.

**Pilot studies** — Before live certification. Consent. Teacher partner. Harm analysis.

**Bias studies** — Planned, not only after a complaint. Locales we ship are in the study.

**Longitudinal validation** — Does this sample predict a later transfer item, not only itself? Week-eight and year-one matter more than day-one shine.

**Continuous improvement** — Failed items return like spaced practice. A hotfix that changes a live credential key is an incident.

**Educational research** — Operating Standards Volume V. No A/B on a child’s official record. Observation can kill a sample that metrics love.

If we cannot show validity evidence, the assessment stays formative or it does not ship.

# Volume XIV — Future Assessment

Technology will change the glass. The sample will not become a spy.

**Continuous assessment** — More formative, better next items. Continuous does not mean a hidden official record of every mouth-sound.

**Invisible assessment** — Only as formative state on the graph (they can see the state). Invisible official scoring is forbidden. If they cannot know they were sampled, it was not assessment. It was watching.

**AI-supported evaluation** — Stronger drafts, tighter tools, same human accountability, same hallucination ban.

**Competency graphs** — Richer `samples` and `maintains` edges. Not a public map of a child.

**Authentic assessment** — More performance and oral in the world. Still criteria. Still no tape by default.

**Simulation-based assessment** — Constrained, labeled, safe. Not a spectacle required to certify Core.

**Collaborative assessment** — Shared tasks with visible presence. Individual claims still name the individual’s class. We do not grade a child for a group’s ghost.

**Lifelong credentials** — Exportable, decaying, maintainable. The person holds the passport.

**Dynamic certification** — Maintenance samples can keep a claim honest. Dynamic is not a subscription that holds learning hostage without a written policy. Dignity still outranks billing theater.

**Human–AI evaluation** — AI drafts. Human signs. Appeal is human. That split does not invert because the model got larger.

The future may add a sensor.  
It may not add a required face, a secret score, or a credential for sitting.

# Volume XV — Assessment Manifesto

Assessment exists to reveal learning, not to judge people.

A sample is a lamp over a class of skill. It shows what held and what failed. It does not show what a child is worth. When we let a number become a name, we have left education and entered a sorting house. This hall is not a sorting house.

Mastery matters more than grades because the world will not present the identical worksheet. A grade is a compression for a calendar. Mastery is a promise about a later hour: they can do a new item of this class, after a gap, without us. If we must choose, we keep the promise and lose the compression.

Evidence outweighs opinion. A teacher’s judgment is evidence when it is tied to an item and a rubric they can show. A model’s fluency is not evidence. A parent’s fear is not evidence. A streak is not evidence. We keep trails: items, classes, dates, levels, decay. We do not keep opinions about a soul.

Fairness is essential to trust. An unfair item is a lie about a child. An inaccessible sample is a locked door we called a test. A camera in a bedroom is not integrity. A rank on a wall is not motivation. People will forgive a hard item. They will not forgive a rigged one.

Every learner deserves another opportunity to improve. Regression is a door back to practice, not a brand. Recovery is the same thread. An appeal is a right. A diagnostic after years away is a kindness. A forever fail is a cruelty we will not encode.

What must never change, even when the scorer is a model we do not have a name for:

We sample a class, not a person.  
We disclose of-learning.  
We do not rank children.  
We do not certify attendance.  
We do not score a soul.  
We do not require a face to learn.  
We do not keep a tape as evidence.  
AI drafts. Humans sign official claims.  
Mastery can fade.  
The next attempt is the point of the number.

The operating system is a hall with a lamp.

If the lamp is honest, they can see the next step.  
If the lamp is a judge, they will learn to hide.

Stay on the line.  
Sample the class.  
Show the trail.  
Let them try again.
